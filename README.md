# sistema-ventas-electromusic
#  Sistema de Ventas y Cotizaciones - ElectroMusic

Aplicación de escritorio (Standalone) desarrollada para optimizar el proceso de ventas y atención al cliente en una tienda de instrumentos musicales y equipos de audio. El sistema permite gestionar catálogos, procesar ventas mediante un carrito de compras interactivo y emitir documentos de facturación.

## Características Principales

* **Interfaz Gráfica Moderna (GUI):** Interfaz intuitiva y amigable desarrollada con CustomTkinter.
* **Gestión de Catálogo:** Importación y visualización del inventario de instrumentos y equipos.
* **Carrito de Compras:** Sistema de agregación de productos con cálculo de totales en tiempo real.
* **Generación Automatizada de PDFs:** Creación instantánea de cotizaciones y facturas exportables a formato PDF listas para imprimir o enviar al cliente.
* **Ejecutable Independiente:** Aplicación compilada para funcionar de manera autónoma sin necesidad de instalar Python en el equipo cliente.

## Tecnologías Utilizadas

* **Lenguaje:** Python 3.x
* **Interfaz Gráfica:** CustomTkinter
* **Generación de Documentos:** Librerías de manipulación de PDF (y manejo de datos).
* **Empaquetado:** PyInstaller / Auto-py-to-exe (para compilar la app de escritorio).
